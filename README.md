# Prerequisits

This project requires cmake 3.30+.
Building and running instructions assume that you are placed in the project root.

# Building

To build the project run `./build`

# Running

To run the project run `./run`

# Bonus

To both build and run the project run `./full`

# Game

Move around with `WASD`
Hit with `Space`
Toggle fullscreen with `F11`

# Editor

- Select an object to place from the Left side
- Place by pressing somewhere on the map to replace an object
- Save by pressing `Save`
